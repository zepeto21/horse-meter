# HORSE METER

테슬라 브라우저에서 쓰는 클래식 택시미터 웹앱 (재미용)

- 미터기: https://zepeto21.github.io/horse-meter/ (짧은 주소: https://bit.ly/4j9oxQS)
- 차량 진단: https://zepeto21.github.io/horse-meter/diag.html (짧은 주소: https://bit.ly/4tbHEOK)

## 기능
- 옛날 택시미터 디자인, 차가 달리면 말이 달리고 멈추면 말도 멈춤
- 거리 측정: 브라우저 GPS (데모 주행 모드 포함)
- 요금: 서울 중형택시 기준 (기본 1.6km 4,800원, 131m·30초당 100원, 시속 15km 미만은 시간요금, 심야 22~04시 자동, 시계외 할증 20%)
- 화면: 테슬라 주행 중(좁은 창)·정차 중(넓은 창)·휴대폰 자동 대응
- 영수증, 최근 주행 50건 기기에 저장

## 휴대폰에서 쓰기
- 휴대폰 브라우저로 미터기 주소를 열면 세로/가로 화면에 맞게 자동으로 바뀌어요.
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(크롬): 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
- 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 전체 화면으로 떠요.

## 개인정보
- 위치 정보는 내 기기 안에서만 계산하고 어디에도 보내지 않아요.
- 주행 기록도 각자 기기 브라우저에만 저장돼요.
